# Pneumonia Detection from Chest X-Ray Images using Transfer Learning

An AI system that classifies chest X-ray images as **NORMAL** or **PNEUMONIA**, built with transfer
learning (MobileNetV2, VGG16 & ResNet50 pretrained on ImageNet) on the
[Chest X-Ray Images (Pneumonia)](https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia)
dataset, plus a Streamlit app for interactive inference.

> ⚠️ **Disclaimer:** This is a research/educational project, not a certified diagnostic tool.
> It has not been clinically validated. Do not use it for real medical decisions — always
> consult a qualified physician or radiologist.

## Overview

| | |
|---|---|
| **Task** | Binary image classification (NORMAL vs. PNEUMONIA) |
| **Approach** | Transfer learning: MobileNetV2 backbone (ImageNet weights) + custom classification head |
| **Training** | Two stages — (1) frozen backbone, train head only; (2) unfreeze top 30 layers, fine-tune at low LR |
| **Class imbalance** | Handled via computed class weights |
| **Evaluation** | Accuracy, precision, recall, AUC, confusion matrix, ROC curve, precision/recall-vs-threshold curve |
| **Deployment** | Streamlit app with adjustable decision threshold |

## Dataset

[Chest X-Ray Images (Pneumonia)](https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia)
(Kermany et al., via Paul Mooney on Kaggle) — ~5,800 pediatric chest X-rays, organized as:

```
chest_xray/
├── train/
│   ├── NORMAL/
│   └── PNEUMONIA/
├── val/
│   ├── NORMAL/
│   └── PNEUMONIA/
└── test/
    ├── NORMAL/
    └── PNEUMONIA/
```

The notebook merges `train` + `val` and creates its own stratified 85/15 split, since the original
`val` folder only has 16 images — too small to trust as a validation set.

### Getting the data

**Option A — Kaggle API:**
```bash
pip install kaggle
# Place your kaggle.json API token in ~/.kaggle/
kaggle datasets download -d paultimothymooney/chest-xray-pneumonia -p ./data --unzip
```

**Option B — Manual download:**
Download from the [Kaggle dataset page](https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia),
unzip it, and place the resulting `chest_xray` folder next to the notebook (the notebook's default
`DATA_DIR = "chest_xray/"` expects it there) — or set `DATA_DIR` to wherever you put it.

**Option C — Kaggle Notebooks:**
If running directly on Kaggle with the dataset attached, set:
```python
DATA_DIR = "/kaggle/input/chest-xray-pneumonia/chest_xray"
```

## Usage

### 1. Train the model

Open and run `pneumonia_detection_transfer_learning.ipynb` top to bottom:

```bash
jupyter notebook pneumonia_detection_transfer_learning.ipynb
```

Steps performed:
1. Load and explore the dataset (class distribution, sample images)
2. Build augmented data pipelines (rotation, zoom, shift, brightness — no horizontal flip)
3. Build the MobileNetV2-based model
4. **Stage 1:** train the classification head with the backbone frozen
5. **Stage 2:** fine-tune the top backbone layers at a low learning rate
6. Evaluate on the held-out test set (metrics, confusion matrix, ROC curve)
7. Visualize sample predictions
8. Save the final model as `pneumonia_detector_mobilenetv2.keras`

### 2. Run the app

Once you have a trained model file in the project folder:

```bash
streamlit run app.py
```

Then open the local URL Streamlit prints (usually `http://localhost:8501`), upload a chest X-ray
image, and view the prediction, confidence score, and an adjustable decision threshold.
